## 🧩 About

**Mafia The Old Country overlay** is a curated list of Mafia The Old Country open-source tools:

- **Overlays** — on-screen helpers, layout notes, visual enhancements, minimap overlay
- **Quality-of-Life Helpers** — inventory catalog, vehicle manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Mission Helper — markers for objectives and collectibles
- Vehicle Spawner — spawn and manage vehicles for study
- Weapon Loadout — customize and test weapon configurations
- Time of Day — adjust environment for research

### 🎨 Visual & UI
- overlay Overlay — highlight NPCs, items, and points of interest
- Minimap overlay — extended overlay for navigation
- Inventory Viewer — browse and organize items
- HUD Customization — toggle UI elements for clarity

### 🏋️ Practice Layout
- Save Position — record and teleport to saved locations
- No Clip — free camera for exploration (single-player only)
- Speed Control — adjust game speed for study (0.1x to 5x)
